# Pedidos Medievais
Projeto full stack criado em aula de back end

## Tecnologias
- node.js
- VsCode
- JavaScript
- JSON
- HTML

## Como Testar
- 1 Clonar este repositório
- Abrir com o VsCode e em um terminal digitar os seguintes comandos
```bash
npm install
npm run dev
```

- Execute o arquivo cliente/index.html com Live server do VsCode
